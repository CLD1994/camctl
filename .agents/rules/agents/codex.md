# Codex 使用约定

## 如何选择模型

遵循下列选择模型的思路, 除非用户明确要求或技能指令明确指定；其余情况皆按此思路进行选择。

- 优先选择便宜的模型来完成边界稳定的检索、调查、批量工作。
  比如 `GPT-6-Luna` 就是个很优秀的执行模型。因为它很便宜，所以你可以根据任务难度更偏好地将其思考强度设置为 `max`，以此来追求更好的执行效果。

- 优秀选择性能与价格均衡的模型来完成代码的实现和测试用例编写。
  比如 `GPT-6.1 Terra` 就是个很优秀的编码模型。你可以根据任务难度更偏好地将其思考强度设置为 `xhigh`。

- 遇到棘手的复杂问题且总是不能很好的解决时，选择使用最顶级的模型来进行分析和决策。
  比如 `GPT-6-Astra` 就是一个面向最严苛工作的前沿模型。更偏好地将其思考强度设置为 `max`。
