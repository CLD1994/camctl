# 分段传输的实际效果与失败结果

## 行为契约与范围

依据[分段传输契约](../../camctl/file-runtime.md#按段提交的流式传输任务)，传输函数在工作线程中顺序读取、写入和同步。目标返回的实际写入数决定已确认写入范围；收到的源字节不等于写入字节，同步成功不等于可靠进度已经入库。所属流程负责停止源、等待实际关闭、保存可靠进度和释放相机机会。

源读取失败、目标写入失败和同步失败均须交付段结果，保留此前效果与实际异常。段结果不自行新增业务尝试、停止整个读取会话或释放机会。源停止情况来自读取会话的完成事实，与目标操作结果独立；未完成关闭、关闭成功、关闭失败必须可区分。结果是返回时的观察，尚未结束的会话仍由所属流程通过 `wait_stopped()` 跟踪。

| 阶段与实际结果 | 已确认写入范围 | 后续操作与失败事实 |
| --- | --- | --- |
| 源读取返回内容，目标完整写入 | 增加实际写入数 | 继续剩余内容；源完成事实独立保留。 |
| 目标返回正数且小于待写长度 | 只增加返回的字节数 | 未取消时继续写同块剩余内容，不重新读取源。 |
| 目标返回零 | 范围保持不变，效果明确 | 返回写入无进展失败，不无限循环，不同步。 |
| 目标返回非法计数，或写入抛出异常 | 保留此前确认的范围，本次调用效果未知 | 返回写入失败及诊断，不把当前整块或异常调用算作成功。 |
| 源读取调用抛出异常，包括关闭错误 | 保留此前确认写入的范围 | 返回读取阶段失败及原异常；读取和关闭双重错误均保留。 |
| 源返回非字节串或超过请求长度 | 不推进会话位置，不写入异常块 | 会话抛出明确读取错误并关闭，段结果保留此前写入和实际关闭事实；不截断异常数据或当成无数据。 |
| 源提前 EOF 或无数据超时 | 保留此前确认写入的范围 | 保留明确原因，不同步，不推进可靠进度。 |
| 新读、写或同步开始前观察到停止 | 保留已返回调用的效果 | 不开始新的普通操作；包括源返回后和短写之后的停止。 |
| 同步已开始，随后收到停止 | 字节范围不变 | 等待并返回实际同步成功或失败，所属流程再判断是否保存进度。 |
| 同步抛出异常 | 字节范围不变 | 保留同步失败及原异常，不能推进可靠进度。 |

| 会话完成事实 | 段结果中的停止依据 |
| --- | --- |
| 会话尚无完成结果，包括正在关闭 | 未确认停止，不等待关闭，不伪造关闭失败。 |
| 会话关闭成功 | 保留完整结束结果，包括实际读取字节数与结束原因。 |
| 会话关闭失败 | 保留实际关闭异常，不能确认停止。 |

两张表独立组合：例如 EOF 后目标写入失败，仍保留源关闭成功；源和关闭同时失败，保留读取异常组以及独立的关闭失败。写入异常后的已确认偏移只是下界，不能用于截断恢复或推进进度；恢复继续使用数据库可靠进度和文件事实。

## 实现责任与验收

1. 分段写入循环按实际计数继续，检查无进展及非法计数，并在每次实际调用前检查停止。覆盖非零起点、连续短写、短写后失败和取消，目标内容必须与确认范围一致；异常调用的额外效果须标为未知。
2. 分段结果边界保存机器分类、原异常及此前已写范围，以源在已有写入后失败的用例验证。同步和目标写入异常遵守相同信息保留规则。通用文件任务传递完整段结果，不将其压缩为错误文本。
3. 读取会话提供非阻塞完成观察，段返回统一取得此事实。覆盖关闭在途、成功和失败，以及目标失败的组合，目标错误不得改变已取得的源结束依据。
4. `ReadSession` 在接收返回值且尚未推进位置时，只接受不超过请求长度的 `bytes`；只有空字节串表示暂无数据。覆盖合法前缀之后的超长、非字节串及非法空值，组合关闭成功和失败，异常块不得写入目标。

使用标准库的缓冲视图及现有完成 Future；短写循环承载本项目的取消与效果记录，不引入通用重试框架。预计修改 `host_files/segments.py`、`devices/read_session.py` 及其测试，具体内部类型与辅助函数可按数据流调整。这不是对外协议变更。

## 验证证据与后续边界

Python 3.11 与 3.12 的 `tests/unit/devices` 和 `tests/unit/host_files` 各通过 183 项，包含 15 项段结果反例和 10 项源返回反例。保留既有 `test_source_stream_protocol_shape` 的 asyncio 标记警告。

两版的 `tests/integration/devices/test_read_session.py`、`test_read_session_settlement.py` 和 `tests/integration/host_files/test_segments.py`、`test_tasks.py` 各通过 38 项。真实文件验证短写和异常前实际写入，真实读取会话区分读取及关闭失败；文件任务组合验证段结果在执行器中完整保留。关闭屏障验证非阻塞观察未完成结果；同步屏障验证取消后仍保留已开始同步的成功或失败。

独立复核核对数据校验位置、短写续写、取消检查、缓冲生命周期、错误出口和源关闭依据。读取与分段的数值入口另由 `test_read_parameters.py` 及分段参数用例覆盖，相关双版本回归各通过 252 项单元和 38 项集成测试。数据库可靠进度、截断恢复、业务重试和相机机会事务仍需各自的后续验证，不能由本任务的测试代替。
