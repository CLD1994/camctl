# 已结束相机任务的输出范围收尾

## 已确认的行为

活动可靠结束、原基准已固定，但文件范围尚未确定时，由后续有效拍摄动作在提前准备期间触发有限的范围收尾。完整目录路径及其连续分页结束依据与文件大小、完成情况和媒体检查分别保存。范围确认后解除原占用，原动作终态、原调用错误和原 RESULTS 尝试预算保持不变。没有有效触发动作时不主动轮询。

独立范围责任复用普通有限尝试、可靠结果页、原基准差集和文件归属保存。范围页不读取元数据；仍遵守原驱动的结束后等待及完整范围条件。目录调用失败保留原错误和未确认状态，次数和间隔有界，不因调度重扫或进程重启重置。

| 状态 | 行为 |
| --- | --- |
| 活动未可靠结束，存在未收场冲突调用或没有有效触发动作 | 不开始范围扫描，沿原执行资格处理。 |
| 已结束、原基准固定、范围未知且新动作进入准备时段 | 按原绑定完整枚举目录，保存范围页及原基准差集归属。 |
| 元数据不可用，但目录范围已完整核实 | 范围事实可以成立，大小、完整性及原失败保持真实状态。 |
| 可靠末页及全部归属已保存 | 同原范围事实保存释放占用，触发新动作重新检查自己的资格。 |
| 扫描失败或本次触发窗口结束 | 不开启新的读取，已发出的调用及保存完成必要收场；保留具体阻碍。 |
