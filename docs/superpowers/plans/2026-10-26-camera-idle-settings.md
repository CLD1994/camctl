# 相机首次准备的省电与 USB 模式设置

## 目标与契约

Action6 和 OSMO 360 II 在本次执行会话首次准备使用对应相机拍摄时，共同请求关闭延时摄影的熄屏省电及选择仅充电。命令值和适用设备由[相机会话设置](../../hardware/camera-control-handoff.md#相机会话设置)维护，执行时机、缓存和失败语义沿用[相机会话准备](../../architecture/camera-parameters.md#相机会话准备)。

公共会话设置按顺序执行：跳过时间设置、关闭自动休眠、关闭延时摄影熄屏省电、选择仅充电，然后执行各机型其余设置和本次拍摄参数。普通录像与原生延时均使用该组合。

| 情况 | 行为 |
| --- | --- |
| 当前设备在本会话尚未可靠接受某条设置 | 在拍摄准备时发送该条命令；准备不发送 START。 |
| 当前设备在本会话已可靠接受某条设置 | 后续准备跳过该条命令，不重复发送。 |
| 普通拍摄准备中设置失败或结果未确认 | 不缓存该条成功，不发送后续设置或 START；保留已可靠接受的前序设置。 |
| 新执行会话 | 清空内存记录，在首次需要拍摄时重新执行。 |
| 软件重启后的恢复准备 | 清除对应设备缓存并重新执行公共设置；设置与存储核验成功后复用接受记录。 |

本项不改变提前准备时间、尝试预算、实际 START 资格或设备结束判定。命令接受结果与真实设备是否保持 ADB 连接分别验证。

## 验证与交付

两机型共用公共命令组合，普通准备及软件重启后的恢复准备均已接入。CPython 3.11.17 设备组件单元 1809 项通过、1 条既有警告，pytest 耗时 69.93 秒，退出 0。新增 14 个用例覆盖两机型两种拍摄准备、复用与新会话、两条命令分别失败、恢复准备成功和失败；新增前 10 个反例在原实现上均失败。

独立复核已核对公共组合、解释器、准备与 START、失败、缓存及恢复路径；已修正文档的适用机型与说明范围。详细证据位于 `.local/verification/camera-idle-settings-20261026/`，正式范围见[验证记录](../../camctl/verification.md#相机首次准备的省电与-usb-模式设置2026-10-26)。本项未更新当前人工环境安装包，未运行集成测试或调用相机。
