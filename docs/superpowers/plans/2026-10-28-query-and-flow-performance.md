# 查询与流程性能优化实施计划

## 目标与边界

报告生成、READ 候选发现及历史读取保留现有业务结果、错误发现、排序、精确数字校验和事务隔离语义，减少重复初始化、扫描、排序和事实查询。本计划不改变数据库格式，不迁移现有环境，不接入相机。

基线为 `2b52c2df`。2026-10-28 的临时诊断表明：报告校验结构首次初始化约需 1.07 秒；READ 每页重复完整性扫描及候选排序，完整枚举 1000／10000 个合成活动候选分别约需 26／1962 毫秒；50 个报告动作的报告子进程执行 8140 次 SELECT。它们分别是固定初始化成本、规模增长成本和事务内查询复用问题，不能将查询数量减少直接换算成端到端提速。

遵照本任务的验证范围，不编写或运行单元测试、集成测试，也不使用测试框架或测试装配。使用临时诊断脚本保留同输入的结果、查询计划、调用次数、阶段耗时和错误事实。阶段完成条件是实现接入生产调用方、必要诊断完成并经过 `gpt-6.1-sol` 评审；这些证据不代替完整软件或真机验收。

## 必须保持的契约

| 对象 | 必须保持的行为 |
| --- | --- |
| 报告校验结构 | 按权威 Schema 和错误登记派生；规则非法仍报错；保留精确数字、引用和延迟字段校验，不改变报告字节。 |
| READ 候选 | 检出原有坏关联、缺流程和重复流程，不能以 JOIN 过滤隐藏错误；保留持有者优先及完整动作排序、DEVICE／HOST 分类和时间资格。 |
| 当前事实复用 | 当前边界 C 只在所属真实事务内复用，冻结报告 H 不代替当前投影上界。READ 发现拥有者可以有限保存完整性检查成功事实，但下一页仍开启新的短只读事务，先实际读取 main 固定快照，再比较同连接的 `data_version` 与 `total_changes`；变化、换连接、范围变化及关闭后失效，不能从已有事务或写事务产生或使用该会话复用事实。 |
| 资源与恢复 | 分页和缓存有界，取消、失败及关闭后释放；优化不增加整份工作集常驻内存，也不影响原 READ、ReadEnd、取消及重试责任。 |

## 执行步骤

三个实现范围不共享业务事实的所有权，可以在独立 worktree 中并行；根 Agent 负责集成、正式进度和整批耗时对照。以下模块划分为实施建议。

- [x] P1 报告首次初始化：定位固定子规则重复检查，在最窄校验构造边界复用可靠规则事实；对照首次初始化和重复调用，保留非法规则及精确数字诊断。`53a47496`、`3192862f` 已集成并通过独立 Sol 评审；三次新进程首次初始化中位数由 1.072 秒降至 0.731 秒，派生义务摘要一致，资源变更、非法规则及返回对象隔离的临时诊断完成。
- [x] P2 READ 候选发现：在相同可靠视图内复用完整性成功事实，同一动作的后续拷贝按主键续读，动作切换仍使用完整业务排序；保持有界内存、坏关联发现和视图失效，对照相同 1000／10000 规模的查询次数及结果顺序。`41fdd3af` 已集成并通过独立 Sol 评审；10000 个同动作候选的中位数 1767→95 毫秒，多动作 1721→751 毫秒，稳定视图中的完整性查询 101→1 次，序列及错误诊断一致。每动作只有少量拷贝的分布仍可能重复完整排序，持续写入会使继续位置保守重启。
- [x] P3 报告历史读取：在实际只读事务内共享实例身份及完整当前边界，及时结束读事务；对照报告选择、固定历史边界、原始报告字节和查询次数。实现提交 `c14d4793` 已通过独立 Sol 评审；50 动作报告子进程 SELECT 8140→7136，两份固定 H 报告的 15499／21184 字节分别一致，新提交、回滚后重读及外部异实例拒绝的临时诊断完成，等待 P4 集成。
- [ ] P4 集成与交付：整合经评审的实现，使用同一版本资源运行必要的临时流程诊断，保存前后数据及未覆盖范围；更新本计划及正式验证记录。

## 调度与交付

P1、P2、P3 分别由明确指定 `gpt-6.1-terra / xhigh` 的执行 Agent 负责；代码评审统一使用 `gpt-6.1-sol / xhigh`。发现需要新增持久化结构或改变业务语义时，先提交具体证据及方案，不在性能修复中悄然扩展数据库和故障范围。

正式结论按诊断环境注明源码身份、计时口径、输入规模和结果一致性；现场部署、真实相机响应、完整软件验收及目标 ARM 主机性能单独保留边界。

### READ 视图与继续位置

| 本页实际状态 | 完整性检查与分页处理 |
| --- | --- |
| 拥有者尚无成功事实，也没有旧分页位置 | 在自有短只读事务内检查，按本次范围读取。 |
| 拥有者尚无成功事实，但已有其他查询种类的旧位置 | 不能证明旧位置与本页属于同一内容版本，清除各查询种类的旧位置并建立新代次；成功取得本页后保存新的可靠视图标记。 |
| 同一连接、数据库、设备范围及实际内容版本未变 | 可以复用完整性成功事实，沿本代次完整排序键继续。 |
| 固定本页快照后发现内容版本变化，包括观察历史尾后、真正读取本页前发生的提交 | 清除各查询种类的旧位置，以新代次从头读取；不能仅重新校验后继续旧游标。 |
| 使用已有事务或写事务 | 独立检查，不使用或发布会话级成功事实；事务仍由原调用者拥有。 |
| 检查、查询、提交失败或取消 | 清除成功事实，不接纳本页继续位置；自有事务执行回滚。回滚失败时沿既有数据库故障信号停用连接，保留原错误和回滚错误。 |
| 本页事务提交成功 | 发布与本页实际快照匹配的成功事实及继续位置，不保留查询游标或结果集合。 |
