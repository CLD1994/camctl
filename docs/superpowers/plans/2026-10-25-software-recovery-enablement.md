# 软件重启恢复配置简化实施计划

## 目标与依据

用户用 `software_recovery.enabled` 选择是否允许自动恢复；驱动自行维护并核对精确固件及原拍摄范围。行为、状态分类和迁移依据见[正式设计](../specs/2026-10-25-software-recovery-enablement-design.md)。已有冻结责任和原重启安全边界保持。

模块和提交拆分是实施建议。当前工作区基于 `26c60172`；不修改准备占用或报告关联，不操作人工验证库，不执行集成测试或真实设备命令。
