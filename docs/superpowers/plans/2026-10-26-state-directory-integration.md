# 状态目录与开发分支集成

目标：将客户端已有功能与 `origin/implement_camctl` 的事务、历史查询和报告优化合并，计划与动作的状态时间通过现有事件关联目录读取。

## 行为契约

状态目录以已校验主行事件为唯一派生来源，创建和真实状态改变写入 `before_status`、`after_status`，其他关联保留空值。报告查询创建至冻结 H 的完整转换，保持事件顺序、原始时钟判断及同 H 末状态；业务计数、报告水位和快照范围保持既有语义。报告装配负责数据库读取，公共投影只消费输入事实。当前开发结构直接修改，报告按统一字段契约生成。

## 实施步骤

- [x] 核对远端事务派生、连接作用域、按需报告恢复和本地差异，按远端结构解决冲突。
- [x] 扩展关联目录及部分索引，接入有限和有界事务，替换全量对象事件扫描；移除报告版本分支及专用升级入口。
- [x] 验证真实受理、事务回滚、冻结重建与索引访问，并执行相关报告、历史、取回组合检查。
- [ ] 合入后续远端异步数据库更新，复验相关路径，再审查差异、记录验证边界并完成集成。
