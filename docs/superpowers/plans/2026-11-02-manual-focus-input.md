# 手动调焦开关与数值输入

## 目标与契约

MF 下的手动调焦以开关表达。关闭时省略 `focus.relative_move`，驱动保留相机执行当时的焦点位置；开启后由用户填写非零整数，驱动在拍摄前执行一次对应的相对移动。开启但尚未填写或输入非法时，保留输入并阻止导出。AF-S 继续执行单次自动对焦。

参数与相机操作由[单张参数规格](../specs/2026-10-20-hasselblad-photo-parameters-design.md#对焦)定义，展示注解由[能力说明](../../architecture/capabilities.md#参数-schema-的展示注解)定义，保存和回显由[客户端编辑规则](../../architecture/client-editing.md#可选数值输入开关)定义。客户端从同源 Schema 生成控件，普通可选数值字段保留原有编辑方式。
