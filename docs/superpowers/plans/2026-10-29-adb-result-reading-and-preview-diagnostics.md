# ADB 结果读取与预览诊断修复

本计划修复 Action6、OSMO 360 II 的结果读取及预览失败消费。行为依据为[拍摄文件核对](../../architecture/camera-capture.md#跨页配对与可靠前页历史)、[预览选择](../../architecture/preview-obtaining.md#产物选择与失败)及[报告失败身份](../../architecture/report-format.md#取回)。实现位置按生产数据流调整，公共错误登记由根 `protocol` 维护。

## 输入与验收边界

结果读取接收原活动、基准、设备绑定、连续游标和本次期限。主页保留完整路径及顺序，新增候选取得必要文件大小；预览配对取得同目录同主干的最新观察。错误必须保留实际输入及工具输出。历史选择及重送沿用原判定，不改变既有产物和交付身份。

| 已保存事实 | 新预览选择 | 原片处理 |
| --- | --- | --- |
| 有有效正式预览 | 沿实际文件资格与大小规则选择。 | 保留既有结果。 |
| 无正式预览，可靠确认 LRF 不存在 | 每份原片保存 `preview_missing`。 | 保留已确认原片。 |
| 无正式预览，曾看到 LRF，但配对、大小或可用性未确认 | 每份原片保存 `preview_unconfirmed`。 | 保留已确认原片。 |
| 无正式预览，来源结果扫描未可靠完成 | 每份原片保存 `preview_unconfirmed`。 | 保留实际已登记原片。 |

## 实施步骤

1. [x] 核对复制的日志、状态库、报告和实际部署源码，定位目录重复扫描、必要元数据失败及报告失败身份问题。保留原件，只读分析。
2. [x] 从公开驱动入口复现单文件模式未复用目录和候选过滤的问题，以及文件长度错误缺少原始输出的问题；接通原目录上下文、候选筛选与浅层配对查询。
3. [x] 在唯一错误登记增加预览未确认；同步 V8 数据表约束、打开核验及 V7 显式升级入口。从同源结果页派生分类，普通及分段选择共用分类。新选择保存依据版本，原选择恢复保持原语义。
4. [x] 客户端按原片区分预览失败，保留真实重复检测和来源关联校验，兼容现存报告。
5. [x] 完成相关单元、类型检查、用户原报告及只读状态库复核，静态核对跨层接线并记录剩余验收范围。

本项不新增或运行集成测试。V7 到 V8 的真实复制、发布和中断恢复，真实相机上的命令选项、结果耗时及目标机部署单独验收；单元替身和历史资料回放不能证明修复后的真实设备速度或升级可用性。实际验证结果记录于[camctl 验证](../../camctl/verification.md)和[客户端验证](../../client/verification.md)。
