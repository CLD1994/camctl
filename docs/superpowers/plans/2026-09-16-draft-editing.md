# 草稿管理与编辑体验实施计划

**目标：** 支持明确删除未导出草稿，按输入状态展示拍摄参数，默认折叠预设，统一普通界面的本地时间显示及选择。

**执行方式：** 当前 Agent 在现有分支逐项实施，不派遣 subagent。

**规格：** [编辑规则](../specs/camctl/client-editing.md)、[草稿保存与删除](../specs/camctl-client/storage-and-recovery.md)。规格中的状态分类、原值保留和失败语义是硬性契约；下述模块位置与接口是基于当前代码的实施建议，可按实际责任边界调整。

## 1. 删除持久化与会话

- [x] 为 `Application.deleteDraft(id, revision)` 增加集成测试：未完成草稿删除并重开数据库、重复删除、版本冲突、已导出拒绝、晚到保存和导出拒绝、其他草稿和请求保留。先运行确认缺失功能导致失败。
- [x] 在 `database.ts` 提供按命名空间和 ID 删除记录的方法；在应用事务内检查存在、导出状态和版本后删除；`http.ts` 注册 DELETE 路由，返回 JSON 成功结果。
- [x] 为 `DraftSession` 增加删除状态和单元测试，覆盖保存完成后删除、失败与未知的区分、成功清除会话、核实结果存在或不存在、核实读取失败保持锁定。先失败再实现。不得以请求异常或缺失列表冒充删除成功。
- [x] App 发起明确确认，使用会话删除方法；删除成功后清除会话和当前选择，移除列表项。按已确认删除的 ID 过滤在途轮询快照，防止旧列表重新显示已删除项。未知结果提供核实按钮。
- [x] 浏览器集成测试验证取消、确认、刷新持久化、无响应成功、无响应失败、数据不可用及操作锁定。

## 2. 表单展示与时间

- [x] 浏览器测试先复现新录像动作无参数时错误打开 JSON；覆盖选择参数类型后表单出现、非对象及未完成输入保留。
- [x] 参数分支区分缺省与非对象，依据规格决策表展示，不自动写入对象。预设使用默认关闭的折叠区域，更新已有测试的操作路径。
- [x] 本地时间用于输入和摘要，删除 UTC 说明；无效值显示修正提示，完整 JSON 保留原值。时间输入点击触发支持的原生选择器，测试点击文本区域和 UTC 保存结果。
- [x] 检查草稿列表和计划记录的同类时间入口，使用统一转换函数；协议 JSON 不变。
