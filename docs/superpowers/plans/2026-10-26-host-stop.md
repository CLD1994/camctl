# 主程序退出时停止 camctl

目标是让主程序通过 C 接入模块停止它拥有的 camctl 调用，终端演示退出时完成同一收场。行为契约由[主程序主动停止](../../host-demo/design.md#主程序主动停止)维护。设备拍摄的取消和重启恢复规则保持各自归属；本计划不增加设备命令。

## 实施步骤

- [x] 补齐公开停止入口和终止状态；登记在途公开调用，停止接收和启动新工作，保留已启动提交的真实结果。
- [x] 为在管的具体子进程增加一次 SIGINT 停止请求，复用原进程组核验、输出和通知处理；排空回调、诊断及日志后结束线程。
- [x] 将终端演示的 quit、exit、Ctrl+C、SIGTERM 接到同一收场入口；即使主线程正在等待 submit，也能开始停止。
- [x] 使用进程、线程与系统接口替身补充单元反例，执行全部 host 单元入口及构建检查；更新接入说明和验证记录，独立审查后提交。

内部状态、文件划分及线程唤醒方式由实施者根据现有结构选择。停止请求必须先禁止调度，等待过程不能占用回调重入所需的全局锁。尚未确认收场不得释放具体子进程的管理责任；现有失败诊断不能因停止被放弃。

## 验证边界

功能实现与单元验证阶段按用户要求仅运行单元测试，不运行集成测试，也不操作真机、当前运行的 host/camctl 或真实状态库。单元测试用受接口约束的替身验证停止顺序、一次信号、未启动与已启动提交、重入与重复停止、故障和关闭期间禁止重启。后续安装按用户的部署要求执行；真实线程、信号及进程组的业务组合行为由后续人工验证。
