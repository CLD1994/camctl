# 动作摘要与图片、视频查看

[客户端设计](README.md) · [全局拍摄契约](../camctl/camera-capture.md)

## 编辑与报告

客户端支持单张拍摄、录像、延时摄影以及现有内置动作。拍摄类型来自公共协议；可选设备和参数来自已启用的设备能力说明。目标设备栏只在拍摄动作中出现。不支持某能力的设备不能被选作其目标，能力切换不丢失各动作类型的独立草稿。预设以设备、拍摄类型及参数类型定位，不跨类别应用。

三种拍摄均要求设备、时间、参数类型和最大允许延迟；拍摄参数按设备 Schema 生成表单及联动选项。延时摄影的张数、持续时间和固定设置由参数规则提供，客户端不另造统一参数字段。报告按全局 Schema 及语义契约接受；取消的单张拍摄、延时摄影可以有正式产物，不能因动作已取消而隐藏文件或禁止后续合法取回。

## 动作的信息层级

每个动作初次显示仅展示摘要，点击展开业务详情。名称、动作类型、执行状态及重要异常始终可见。摘要按实际报告汇总已知产物数量和本地核验情况；使用“已报告”描述数量，不推算设备未报告的文件。不把没有产物明细解释为零产物。动作完成、主机发布与本地收到分别展示，页面表达来自最近应用报告的状态，不模拟设备实时进度。

业务详情包含计划时间、目标设备、简明执行结果、产物分组及适用操作。技术详情单独折叠，包含实例 ID、原始与生效参数、详细结果、错误码、摘要和每次交付记录。未知结果保留原值供诊断，摘要显示信息尚未确认，不能默认为成功。

| 动作情况 | 摘要要求 |
| --- | --- |
| 等待或执行中 | 展示当前状态、实际等待原因或可靠采集进度 |
| 成功 | 展示动作结果；有已报告产物则按类型汇总 |
| 失败、取消、过期 | 状态与简短原因仍可见；已保留产物继续汇总 |
| 部分文件未收到或核验失败 | 分别计数；不能被动作成功覆盖 |
| 仅有取回交付、来源产物快照缺失 | 保留交付与已知关联，类型不明的文件放入其他文件 |

计划默认展开，动作默认收起。报告刷新及计划折叠再展开保留用户的动作展开状态，切换计划按新记录初始化。折叠详情不加载其媒体内容。

## 产物分组、分页与选择

以 `output_id` 聚合一个产物的多次独立交付，交付仍保留各自身份、状态、本地副本和错误。录像内部生成的原片与修复成品有不同产物身份，不合并。取回动作只呈现属于本次取回的交付，不能用其他取回的成功副本表示本次已收到。

按报告的 `media_type` 分成视频、图片、其他文件；未知不能根据动作名称推测。每组独立分页，每页最多 12 个产物。显示数量、页码及上一页/下一页；空组不显示，页数缩小时收敛到最后有效页。稳定使用已保存产物顺序，轮询不重置当前页。提供全部、可查看、未收到、需处理筛选；改变筛选回到第一页。

| 该范围内一个产物的交付及本地状态 | 分类 |
| --- | --- |
| 至少一份已核验且可读取的副本 | 可查看；其他交付异常仍在详情表达 |
| 无可查看副本，存在核验失败或文件不可用 | 需处理 |
| 无以上情况 | 未收到可查看文件，具体区分未导入、等待报告和核验中 |

动作级操作可以准备取回全部产物；已知文件可以逐项或全选当前页，准备取回所选产物。选择以产物 ID 保留，翻页不清空；始终显示总选择数和清空选择。全选明确标注当前页，批量操作不隐式扩大范围。清理源产物放在更多操作中，保留现有加入草稿并导出的流程，不直接执行设备操作。

## 图片与视频文件流程

报告和媒体文件可混合导入，图片与视频共用完整上传、可靠保存、精确文件名关联、大小与 SHA-256 核验、重复导入、补发替换及重启恢复流程。图片先到时等待有效报告，后到时自动关联；分页不暂停后台工作。原文件始终保留原始字节，缩略展示不替换原文件。

| 本地文件与核验情况 | 界面及读取 |
| --- | --- |
| 尚未完整保存、等待报告、核验中或核验不符 | 展示对应状态，不开放预览和下载 |
| 已核验但缺失或不可读 | 显示文件不可用，不能继续宣称可查看 |
| 已核验且可读取，内容类型为支持的图片 | 当前页显示缩略图，点击打开大图，可下载原文件 |
| 已核验且可读取，内容类型为支持的视频 | 提供播放器与原文件下载 |
| 已核验且可读取，格式无法预览或浏览器解码失败 | 提示无法预览，保留原文件下载；核验结果不改为失败 |

图片预览支持 JPEG、PNG、WebP、GIF；其他格式保留文件和状态并提供合格原文件下载。以报告内容类型确定内联响应，未支持或未知类型使用下载响应，不以内联 HTML/SVG 执行文件内容。大小和摘要核验不等于媒体解码验证。

缩略图采用当前页图片的受控尺寸展示，仅当前页请求媒体；本轮不生成新的持久化缩略文件。大图弹窗支持关闭、上一张、下一张及 Escape、左右方向键；导航范围为当前筛选结果中可预览的图片，可跨页，首尾禁用，不跳到未收到文件。打开时焦点进入弹窗，关闭后回到触发控件。报告更新使当前图片不可用时，停止展示并说明原因，不继续使用失效副本。大图只请求当前图片，不预加载整组原图。

## 验收

分别验证仅支持单张、仅支持录像、仅支持延时、多能力与空设备目录；保存、导出及恢复类型草稿；三种来源的组取回；新动作报告的成功、失败、取消保留与非法状态组合。

用一个视频加至少 100 张图片验证默认摘要、分组、分页、跨页选择、过滤、大图键盘操作和跨页导航。覆盖同一产物多次交付、取回部分失败、图片先到、报告先到、核验失败后正确补发、重启恢复、格式不可预览及文件不可读取。分别检查桌面和窄屏布局，不改变日常演示数据。
