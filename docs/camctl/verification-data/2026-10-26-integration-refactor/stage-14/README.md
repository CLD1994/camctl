## 失败数据库与缺项

仅保存四个已失败用例的 `state.db`：旧 bootstrap 的一个共同失败代表、新 bootstrap 同一代表、新 bootstrap 内额外 read 失败，以及独立新 read 单节点失败。复制前逐项检查 `fuser -v` 没有活动持有者；原路径没有 WAL、SHM 或 journal sidecar。发现的零字节会话、准入和报告锁文件只记录在 manifest 中，没有复制；原件未打开或修改。没有复制完整临时目录、通过用例数据库或容量运行的成功数据库。

本目录有 98 个 gzip 载荷，解压后共 4,916,108 字节，压缩后共 340,476 字节。缺项与范围见 [manifest.json](manifest.json)。所有新 gzip 载荷都以 mtime 0 编码；manifest 逐项记录压缩前后长度及 SHA-256，并记录 JSON/XML 解压解析结果。原始证据仍按各自来源路径保存，不将差异源码或不同源码指纹拼为一个运行。
