# 集成测试重构的历史证据

当前目标、进度、接口问题和最近结果统一见[工作记录](../../integration-test-refactor-2026-10-26.md)。本目录只保存历史证据，不同步维护另一份进度。

材料按 `stage-N/` 保存。各目录的 `manifest.json` 记录当次范围、源码身份、载荷及限制，日志和 JUnit 保存实际结果；较早阶段的 README 另解释其特定诊断上下文。不同源码、范围或计时口径不能相加为一次全量通过或直接作为提速对照。

`.json.gz`、`.xml.gz`、`.log.gz` 可用 `gzip -dc 文件路径` 查看。压缩文件的原始与压缩摘要按各自清单识别；冻结源码、后补复验与历史缺项分别处理，不用后续源码补造旧运行内容。

新增证据直接由工作记录链接到对应清单，无需再增加重复进度摘要或更新本页的逐批列表。
