`tools/` 保存实际使用的收集插件、执行脚本与差异核对脚本，原命令及源码身份由回执保存。`workers/` 按组保留审计引用的定向日志，路径沿原工作区 `.local/` 以下的相对位置组织。原回执中的绝对路径标识执行现场，读取本目录的集中收集和组合结果无需原临时目录。

`.gz` 文件使用 gzip 压缩。旧缓存文件在两次收集中均报错，不能计作覆盖已执行；日志与实际节点清单共同保留。静态函数数、收集节点数及实际执行结果分别解释，不能互相替代。

在任意目录执行 `python /absolute/path/to/verify.py`，可以通过[归档核对脚本](verify.py)检查文件摘要、解压结果、节点集合差与组合计数。它核对已保存证据，不重新执行测试，也不依赖原工作区和临时目录。
