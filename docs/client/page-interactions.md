# 页面反馈与长列表

## 选择控件

网页中的下拉选择统一使用基于 Base UI 的公共组件。表单与工具栏共用边框、箭头、悬停、键盘焦点、选中标记和禁用样式，表单控件占满字段宽度。弹出列表在页面外层渲染，按视口剩余空间调整位置；长列表可滚动，长选项可换行。

控件只负责展示和提交选择，草稿值及候选资格仍由业务规则决定。选择的字符串标识交回字段处理函数，由该函数完成枚举值、布尔值和报告编号等类型转换。

| 编辑状态 | 当前值或操作 | 行为 |
| --- | --- | --- |
| 禁用 | 任意值 | 保留显示，关闭已展开列表，禁止修改；恢复编辑后保持关闭 |
| 可编辑 | 尚未选择 | 显示选择提示，不自动代填；只有允许清空的字段才可主动选择空项 |
| 可编辑 | 有效值 | 显示对应标签；确认另一可选项后提交新值，确认同一项不重写草稿 |
| 可编辑 | 非法或已不可用的旧值 | 保留业务提供的原值说明，将该项标为不可选；允许用户选择合法项修正 |
| 可编辑 | 候选列表刷新或动作类型切换 | 按业务状态更新显示，不接受组件内部自动回退产生的写入 |

鼠标点击展开并选择；键盘可用方向键打开列表、移动焦点或输入文字定位，Enter 确认，Escape 关闭并返回触发控件。浏览列表、取消选择与刷新候选均不修改草稿。

报告范围仍要求主动选择完整或增量同步。没有可靠的已保存报告时，完整同步可选，增量同步禁用并显示缺少起点的说明；选择增量同步后必须明确选择可靠起点。表单整体因导出、删除或追加核实而禁用时，下拉选择继承同一状态。

## 操作反馈

瞬时操作反馈属于发起操作的页面，异步完成时仍归属该页面。每次新反馈从产生时计时 3 秒；同文案的再次反馈重新计时，旧计时不能清除新反馈。离开页面不暂停计时。预设操作反馈同样适用。

| 反馈状态 | 当前页面 | 结果 |
| --- | --- | --- |
| 未满 3 秒且未被替换 | 所属页面 | 显示 |
| 未满 3 秒且未被替换 | 其他页面 | 隐藏，计时继续 |
| 已满 3 秒或已被替换 | 任意页面 | 不再显示原反馈 |

| 信息种类 | 页面范围 | 消失条件 |
| --- | --- | --- |
| 删除、递交标记、预设保存、能力重新加载等操作反馈 | 所属页面 | 产生后 3 秒或被后续反馈替换 |
| 操作错误 | 发起页面 | 下一次操作或问题被处理 |
| 未保存编辑、追加结果待核实 | 计划页 | 完成保存或核实 |
| 后台文件处理错误 | 文件导入页 | 处理状态解除 |
| 服务连接错误、历史覆盖缺口 | 使用这些状态的页面 | 可靠状态恢复 |

## 计划记录折叠

计划详情和每个动作均可独立展开、折叠；计划初次默认展开，动作默认只显示摘要，详见[动作摘要与媒体查看](result-browsing.md)。折叠后仍显示名称及最新状态，详情隐藏。折叠操作不修改请求、报告或执行状态。相同记录的轮询更新和父计划折叠再展开保留动作的折叠状态；切换记录按新记录初始化。控件支持键盘，表达当前展开状态。

## 文件导入分页

按文件分页，每页最多 10 条，最新导入在前；同一批次可以跨页，每页保留批次标识。分页只影响展示，所有上传、后台处理、报告合并和视频校验仍继续进行。

| 情况 | 页面行为 |
| --- | --- |
| 无导入记录 | 空状态，不显示分页 |
| 首次打开 | 第一页 |
| 翻页 | 显示对应文件及最新处理状态 |
| 定时刷新 | 保留当前页码 |
| 主动选择或拖入新文件 | 回到第一页 |
| 总页数减少，当前页超界 | 显示最后一个有效页 |

显示总文件数、页码、上一页和下一页；首尾按钮禁用。不得通过分页截断实际导入任务。
