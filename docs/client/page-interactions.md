# 页面反馈与长列表

## 选择控件

网页中的下拉选择统一使用基于 Base UI 的公共组件。表单与工具栏共用边框、箭头、悬停、键盘焦点、选中标记和禁用样式，表单控件占满字段宽度。弹出列表在页面外层渲染，按视口剩余空间调整位置；长列表可滚动，长选项可换行。

控件只负责展示和提交选择，草稿值及候选资格仍由业务规则决定。选择的字符串标识交回字段处理函数，由该函数完成枚举值、布尔值和报告编号等类型转换。

| 编辑状态 | 当前值或操作 | 行为 |
| --- | --- | --- |
| 禁用 | 任意值 | 保留显示，关闭已展开列表，禁止修改；恢复编辑后保持关闭 |
| 可编辑 | 尚未选择 | 显示选择提示，不自动代填；只有允许清空的字段才可主动选择空项 |
| 可编辑 | 有效值 | 显示对应标签；确认另一可选项后提交新值，确认同一项不重写草稿 |
| 可编辑 | 非法或已不可用的旧值 | 保留业务提供的原值说明，将该项标为不可选；允许用户选择合法项修正 |
| 可编辑 | 候选列表刷新或动作类型切换 | 按业务状态更新显示，不接受组件内部自动回退产生的写入 |

鼠标点击展开并选择；键盘可用方向键打开列表、移动焦点或输入文字定位，Enter 确认，Escape 关闭并返回触发控件。浏览列表、取消选择与刷新候选均不修改草稿。

报告范围仍要求主动选择完整或增量同步。没有可靠的已保存报告时，完整同步可选，增量同步禁用并显示缺少起点的说明；选择增量同步后必须明确选择可靠起点。表单整体因导出、删除或追加核实而禁用时，下拉选择继承同一状态。

## 后续操作弹窗

准备状态同步，以及从计划、动作或产物准备后续操作，使用共同的模态对话框。弹窗打开后，焦点进入弹窗；Tab 和 Shift+Tab 在弹窗内移动，背景控件不能获得键盘焦点。下拉选项在外层渲染时仍属于弹窗交互范围；选项列表展开期间，Escape 先关闭列表并返回选择控件，再次按 Escape 才关闭弹窗。

| 操作状态 | 关闭或导航行为 |
| --- | --- |
| 没有操作正在提交或核实 | 返回按钮或 Escape 关闭弹窗，焦点回到本次发起入口；点击背景不关闭 |
| 操作正在提交或核实 | 返回、Escape 和背景点击不能关闭弹窗，也不能重复提交 |
| 本次尝试失败，或追加结果仍须核实 | 可以关闭弹窗；固定目标、动作、追加基线和核实责任继续保留，再次进入沿用同一操作 |
| 追加可靠完成并成功接纳，或查看目标读取成功 | 进入目标草稿或草稿列表，弹窗关闭，焦点转到可见的草稿入口 |
| 查看目标读取失败 | 保留弹窗及原操作资料，显示实际错误 |

关闭弹窗只改变显示状态，不撤销已经发出的请求，也不改变请求是否成功的判定。追加状态的完整规则见[动作显示状态与追加接纳](../architecture/client-editing.md#动作显示状态与追加接纳)。原入口已经卸载或不可见时，焦点回到可用的计划或草稿入口。

## 计划页签

草稿和计划记录构成一个页签组，每项与对应面板关联。活动页签是组内唯一的 Tab 停靠点；左右方向键在两项之间循环移动并激活，Home 选择第一项，End 选择最后一项。Tab 离开页签组后进入后续控件。

页签切换只选择显示内容。草稿会话、未完成输入、已导出请求身份及只读要求继续遵守[计划编辑与交接](plans.md)和[草稿保存规则](storage-and-recovery.md)。切换本身不改写草稿，也不重新创建请求。

## 草稿校验和错误定位

草稿在主要编辑区域之前显示中文校验摘要。每项说明所属计划或动作以及出错字段，提供可点击的定位入口。原始路径、错误码和原始诊断保留在可展开的技术详情中。字段错误通过 `aria-invalid` 标识，控件通过 `aria-describedby` 关联当前错误说明；修正后关联随当前校验结果更新。

| 校验对象 | 定位结果 |
| --- | --- |
| 表单中有准确对应的公共字段或参数字段 | 展开所属动作及必要的详情，聚焦该字段 |
| 参数或业务策略正在通过 JSON 控件编辑，错误位于其内部路径 | 聚焦负责该对象的 JSON 控件 |
| 尚未完成的数值或 JSON 输入 | 聚焦对应的未完成输入原文本，包括根输入；不能以此前的合法值代替 |
| 没有准确控件、动作不是对象、根 JSON 无法解释，或路径有歧义 | 展示并聚焦整份计划 JSON，保留原文和全部编辑资料 |
| 已保存的未完成输入键无法解释为标准路径 | 仍显示原键、原文和错误，定位到该未完成输入控件；应用修正按现有规则报告路径错误 |

定位从当前草稿及稳定动作显示身份计算，兼容现有点号/数组路径和 JSON Pointer。根未完成输入与整份计划 JSON 是两个独立控件。特殊属性名不能无歧义解释时，不把它猜测为另一字段。展开、聚焦或切换 JSON 显示不触发正文修改或保存，也不清除自动预览、暂存参数或未完成输入。Schema 分支及未知关键词使用不臆测具体取值的中文提示，技术详情继续提供完整诊断。

## 拍摄视频大小提示

普通录像和延时摄影动作在拍摄参数编辑区域显示“预计视频大小”，表单模式和参数 JSON 模式共用当前结果。用户修改参数、应用预设、切换设备或类型、重新打开草稿后，页面根据当前参数和实际启用的能力说明重新计算。预览视频和独立照片不计入；其他动作不显示该区域。

有效结果显示约数、预计成片时长和参考码率，并说明实际大小可能随拍摄内容和编码结果变化。大小采用十进制 MB 或 GB，`1 MB = 1,000,000 字节`，`1 GB = 1,000 MB`；参考码率采用 Mbps，即每秒百万比特。显示时才舍入，极小的正估算值以小于某个显示界限表达，不显示为零。

无法估算时，页面区分未提供规则、输入未完成、选择或参数无效、所需值缺失、当前选项没有估算依据及计算无有效结果。必要时显示 Schema 中的字段名称、实际参数路径或既有加载诊断。相关未完成输入立即撤下旧数值；其他动作或无关公共字段的问题不遮蔽当前结果。完整判定顺序与重载恢复条件见[拍摄视频大小估算](../architecture/client-editing.md#拍摄视频大小估算)。

重载进行中和结果尚待核实时，页面显示对应状态并暂停数值。后续合格状态观察成功后，页面按实际启用说明恢复；仍使用此前说明时同时显示该来源提示。查看提示、折叠动作、切换表单与 JSON 或计算结果本身不保存草稿，也不改变自动预览。用户实际编辑参数仍遵守原有保存规则。

## 文件选择及窄屏显示

文件选择使用原生文件输入，键盘焦点由用户可见的外层选择按钮显示。获得焦点或取消文件选择不创建导入批次、不上传文件。实际导入仍遵守[文件导入与结果查看](files-and-status.md)。

窄屏下编辑器标题与工具按钮分行，按钮允许换行，长名称和标识可以在容器内折行。常用辅助文字使用统一的清晰颜色；焦点和错误状态不能仅依靠透明控件自身的轮廓表达。

## 操作反馈

瞬时操作反馈属于发起操作的页面，异步完成时仍归属该页面。每次新反馈从产生时计时 3 秒；同文案的再次反馈重新计时，旧计时不能清除新反馈。离开页面不暂停计时。预设操作反馈同样适用。

| 反馈状态 | 当前页面 | 结果 |
| --- | --- | --- |
| 未满 3 秒且未被替换 | 所属页面 | 显示 |
| 未满 3 秒且未被替换 | 其他页面 | 隐藏，计时继续 |
| 已满 3 秒或已被替换 | 任意页面 | 不再显示原反馈 |

| 信息种类 | 页面范围 | 消失条件 |
| --- | --- | --- |
| 删除、递交标记、预设保存、能力重新加载等操作反馈 | 所属页面 | 产生后 3 秒或被后续反馈替换 |
| 操作错误 | 发起页面 | 下一次操作或问题被处理 |
| 未保存编辑、追加结果待核实 | 计划页 | 完成保存或核实 |
| 后台文件处理错误 | 文件导入页 | 处理状态解除 |
| 服务连接错误、历史覆盖缺口 | 使用这些状态的页面 | 可靠状态恢复 |

## 计划记录折叠

计划详情和每个动作均可独立展开、折叠；计划初次默认展开，动作默认只显示摘要，详见[动作摘要与媒体查看](result-browsing.md)。折叠后仍显示名称及最新状态，详情隐藏。折叠操作不修改请求、报告或执行状态。相同记录的轮询更新和父计划折叠再展开保留动作的折叠状态；切换记录按新记录初始化。控件支持键盘，表达当前展开状态。

## 文件导入分页

按文件分页，每页最多 10 条，最新导入在前；同一批次可以跨页，每页保留批次标识。分页只影响展示，所有上传、后台处理、报告合并和视频校验仍继续进行。

| 情况 | 页面行为 |
| --- | --- |
| 无导入记录 | 空状态，不显示分页 |
| 首次打开 | 第一页 |
| 翻页 | 显示对应文件及最新处理状态 |
| 定时刷新 | 保留当前页码 |
| 主动选择或拖入新文件 | 回到第一页 |
| 总页数减少，当前页超界 | 显示最后一个有效页 |

显示总文件数、页码、上一页和下一页；首尾按钮禁用。不得通过分页截断实际导入任务。
