# 页面反馈与长列表

## 草稿保存反馈

正常的等待保存、保存中和已保存不展示常驻说明或保存时间，简短状态仅向辅助技术提供。自动预览控件的位置在这些正常状态之间保持稳定。普通编辑按[自动保存时机](storage-and-recovery.md#草稿的自动保存与并发冲突)合并连续输入，导出等显式操作仍先完成必要保存。

保存失败、冲突、结果未知及接纳异常时，显示实际保存状态、完整输入的保存依据、诊断和相关恢复操作，具体资格遵守[保存与恢复规则](storage-and-recovery.md)。布局不限制异常文字的高度；窄屏允许说明和操作换行。

| 保存状态 | 显示与操作 |
| --- | --- |
| 当前输入已保存，或普通自动保存已安排、正在执行 | 不展示常驻保存说明和保存按钮。 |
| 核实旧结果后仍有待存输入，且没有安排自动保存 | 展示实际保存依据与“保存当前输入”；核实操作本身仍只读取旧结果。 |
| 保存失败、冲突、结果未知或其他恢复责任未结束 | 保留具体诊断与对应的核实、重试或版本选择入口。 |

## 选择控件

网页中的下拉选择统一使用基于 Base UI 的公共组件。表单与工具栏共用边框、箭头、悬停、键盘焦点、选中标记和禁用样式，表单控件占满字段宽度。弹出列表在页面外层渲染，按视口剩余空间调整位置；长列表可滚动，长选项可换行。

控件只负责展示和提交选择，草稿值及候选资格仍由业务规则决定。选择的字符串标识交回字段处理函数，由该函数完成枚举值、布尔值和报告编号等类型转换。

| 编辑状态 | 当前值或操作 | 行为 |
| --- | --- | --- |
| 禁用 | 任意值 | 保留显示，关闭已展开列表，禁止修改；恢复编辑后保持关闭 |
| 可编辑 | 尚未选择 | 显示选择提示，不自动代填；只有允许清空的字段才可主动选择空项 |
| 可编辑 | 有效值 | 显示对应标签；确认另一可选项后提交新值，确认同一项不重写草稿 |
| 可编辑 | 非法或已不可用的旧值 | 保留业务提供的原值说明，将该项标为不可选；允许用户选择合法项修正 |
| 可编辑 | 候选列表刷新或动作类型切换 | 按业务状态更新显示，不接受组件内部自动回退产生的写入 |

鼠标点击展开并选择；键盘可用方向键打开列表、移动焦点或输入文字定位，Enter 确认，Escape 关闭并返回触发控件。浏览列表、取消选择与刷新候选均不修改草稿。

报告范围仍要求主动选择完整或增量同步。没有可靠的已保存报告时，完整同步可选，增量同步禁用并显示缺少起点的说明；选择增量同步后必须明确选择可靠起点。表单整体因导出、删除或追加核实而禁用时，下拉选择继承同一状态。

## 后续操作弹窗

准备状态同步，以及从计划、动作或产物准备后续操作，使用共同的模态对话框。弹窗打开后，焦点进入弹窗；Tab 和 Shift+Tab 在弹窗内移动，背景控件不能获得键盘焦点。下拉选项在外层渲染时仍属于弹窗交互范围；选项列表展开期间，Escape 先关闭列表并返回选择控件，再次按 Escape 才关闭弹窗。

| 操作状态 | 关闭或导航行为 |
| --- | --- |
| 没有操作正在提交或核实 | 返回按钮或 Escape 关闭弹窗，焦点回到本次发起入口；点击背景不关闭 |
| 操作正在提交或核实 | 返回、Escape 和背景点击不能关闭弹窗，也不能重复提交 |
| 本次尝试失败，或追加结果仍须核实 | 可以关闭弹窗；固定目标、动作、追加基线和核实责任继续保留，再次进入沿用同一操作 |
| 追加可靠完成并成功接纳，或查看目标读取成功 | 进入目标草稿或草稿列表，弹窗关闭，焦点转到可见的草稿入口 |
| 查看目标读取失败 | 保留弹窗及原操作资料，显示实际错误 |

关闭弹窗只改变显示状态，不撤销已经发出的请求，也不改变请求是否成功的判定。追加状态的完整规则见[动作显示状态与追加接纳](../architecture/client-editing.md#动作显示状态与追加接纳)。原入口已经卸载或不可见时，焦点回到可用的计划或草稿入口。

## 计划页签

草稿和计划记录构成一个页签组，每项与对应面板关联。活动页签是组内唯一的 Tab 停靠点；左右方向键在两项之间循环移动并激活，Home 选择第一项，End 选择最后一项。Tab 离开页签组后进入后续控件。

页签切换只选择显示内容。草稿会话、未完成输入、已导出请求身份及只读要求继续遵守[计划编辑与交接](plans.md)和[草稿保存规则](storage-and-recovery.md)。切换本身不改写草稿，也不重新创建请求。

## 草稿并发冲突交互

用户在两页打开同一份草稿时，一页成功保存的版本可能晚于另一页已经读取的版本。客户端按[草稿的自动保存与并发冲突](storage-and-recovery.md#草稿的自动保存与并发冲突)判断能否接纳这份更新。页面的保存区持续显示当前输入是否已经可靠保存、是否正在保存或核实，以及是否需要选择版本；这些状态不能在 3 秒后自行消失。

| 当前事实 | 页面反馈 |
| --- | --- |
| 本页有尚未确认保存的编辑 | 显示未保存状态，保留全部当前输入；不能继续把上一版本的已保存提示用于当前内容 |
| 保存请求正在执行 | 显示保存中；普通保存期间仍允许继续输入，提示不得把在途版本当作最新输入已经保存 |
| 当前完整输入已经存在于可靠保存版本中 | 显示已保存及该版本的保存时间；时间来自后端保存记录，不能用本页发送请求或收到响应的时刻代替 |
| 保存明确未完成 | 显示保存失败及实际原因，保留本页完整输入，提供相应重试入口 |
| 保存或冲突选择的结果仍未确认 | 显示待核实及重新核实入口；重复核实沿用同次操作，不把相同正文显示为操作成功 |
| 按权威规则接纳普通远端更新 | 当前编辑区和保存时间更新为可靠版本；无须要求用户处理没有实际差异的冲突 |
| 双方完整内容不同，需要用户选择 | 持续说明向原草稿的自动保存已暂停、本页输入仍在当前会话中，并提供查看差异及版本选择入口 |
| 原草稿已经导出或删除 | 明确显示相应事实及原草稿不可覆盖的原因；本页输入仍按权威规则保留，可以另存为新草稿 |

“已保存”与计划是否通过校验分别展示。输入尚未完成但已经可靠保存时，页面同时显示保存事实和真实输入问题，不能把业务校验错误说成保存失败。冲突中的本页未保存输入仅在当前会话内存中保留；刷新或关闭继续使用既有未保存提醒，不显示跨刷新恢复承诺。

### 完整版本的差异面板

差异面板明确区分“本页版本”和“已保存版本”，显示各自的计划名称、动作数量及动作顺序，并标明已保存版本的保存时间及当前是否仍可编辑。两侧动作按各自顺序独立展示；动作的改名、重排、增加或删除不能仅凭同名猜测两侧是一项动作。动作内容无法可靠解释时保留该侧实际原文和诊断，不补造字段对应关系。

面板以完整草稿为比较对象。除当前正文外，还要说明未完成输入、停用动作类型、参数类型与对象模式内容，以及自动预览开关、稳定动作身份和派生关联是否存在差异，并允许展开查看对应内容。不能仅以相同正文、动作数量或错误数量说明两个版本一致。业务摘要使用用户可以理解的中文说明；原始 JSON、内部路径、字段标识及版本号放在可展开的技术详情中，仍完整保留原文及数字事实。

用户查看差异或关闭面板时，本页输入、冲突状态及暂停自动保存的责任继续保留。尚未提交选择时，用户可以修正本页输入；本页内容或可靠的已保存版本变化后，差异随之更新，旧的采用或替换确认资格立即失效。

| 版本选择 | 操作前呈现及资格 |
| --- | --- |
| 将本页另存为新草稿 | 标为推荐选择，说明将完整本页内容保存为独立草稿；不要求先把本页内容写回原草稿 |
| 使用已保存版本 | 已保存版本可靠且原草稿仍可编辑时提供；明确说明将放弃全部本页未保存输入，包括停用分支及自动预览资料，用户确认后才接纳 |
| 用本页版本替换已保存版本 | 已保存版本可靠且原草稿仍可编辑时提供；先展示完整差异，再确认替换当前展示的版本。远端再次变化时更新差异并要求重新选择，不能沿用旧确认 |
| 原草稿已经导出或删除 | 仅提供另存来保留本页输入，不能覆盖原记录；已导出时提供只读计划记录入口，已删除时提供草稿列表入口 |
| 当前读取失败，无法核实已保存版本或目标状态 | 保留此前可靠观察及本页输入，显示读取问题；不能自动采用，也不能根据旧观察授权新的替换，重新读取后按权威规则判断资格 |
| 原请求仍在途，或尚不能可靠读取原操作的目标状态 | 版本选择不能绕过原操作核实，所有会发出新操作或丢弃当前输入的选择均暂停；显示实际阶段，提供核实入口及原因 |
| 旧保存请求已经结束，可靠较新当前版本已取得，但无法证明旧写入是否曾成功 | 按权威规则证明旧条件写入不能再改变目标后，说明旧结果仍不可确认，开放针对完整当前版本的适用选择；内容不同可另存、采用或替换，完整内容相同可明确采用已保存版本结束旧调度，无须再写入相同内容。不能要求丢失的旧回执才能选择，也不将旧写入说成成功 |
| 选定操作正在提交、核实或等待异常处理决定 | 禁止再次选择、修改本页内容、导出、删除及追加；显示该操作实际阶段。关闭面板不取消已发请求，也不丢弃同次操作的核实或待决定责任 |

另存、采用及替换的正常完整接纳成功后，页面直接进入相应目标；输入、身份和恢复责任遵守[另存的确认与重试](storage-and-recovery.md#另存的确认与重试)及[采用与替换的异常处理](storage-and-recovery.md#采用与替换的异常处理)。需要用户决定如何继续的异常按下节显示，三个版本选择仍由差异面板提供。

### 并发选择异常弹窗

用户已经选择另存、采用或替换后，客户端遇到需要决定如何继续的异常时自动打开共用模态弹窗。弹窗说明所选操作、已经可靠完成的步骤、当前未完成的步骤，以及重试和放弃各自会做什么。正常成功直接进入目标，不先显示异常弹窗。此弹窗仅用于草稿并发选择及另存异常；双方版本不同仍使用完整差异面板中的三个版本选择。

弹窗固定提供“重试”和“放弃”两个操作按钮，按钮资格及执行结果按保存专题的状态表计算，不由错误文案推测。重试继续完成本次操作；若另存已经可靠创建，但新草稿已删除或导出，正文在点击前明确说明将使用保留内容另存一份新草稿，此次点击构成独立新决定。采用或替换因原草稿终态失去确认资格时，按[采用与替换的异常处理](storage-and-recovery.md#采用与替换的异常处理)更新可靠事实并提供仍适用的选择，共用弹窗不能据此自动创建草稿。放弃说明停止本次操作但保留完整本页输入及已经完成的后端写入。创建结果未知、依据无效或缺少可靠资格时，放弃暂不可用，并说明需要先重试核实；请求或核实正在执行时两个按钮均不能重复执行操作。

异常待决定期间，源草稿保持领域层的编辑和写操作限制，隐藏弹窗不能解除。页面保存区持续提供重新打开入口及实际阶段；待决定与创建待核实分别展示，目标已导出或删除不能继续显示为创建待核实，也不能使待决定提示消失。普通状态观察继续更新可靠事实；导出观察引起的导航、草稿切换和视图重建必须保留可见提示及重新打开入口，不得先让用户继续修改这份草稿。

弹窗自动打开后焦点进入说明区域或不触发操作的焦点位置，Enter 只激活当前聚焦控件。Tab 和 Shift+Tab 留在弹窗内；背景控件不能获得焦点，点击背景不关闭。请求或核实执行期间，Escape 和关闭控件不可用；其余时候 Escape 或关闭控件只隐藏弹窗，保留待决定限制和重新打开入口，不能等同点击放弃。隐藏后焦点回到可见的重新打开入口；原入口不存在时回到保留该责任的草稿入口。

重试需要重新确认版本时，显示更新后的完整差异并把焦点移入确认步骤，不能自动提交选择。重试成功进入目标后，焦点移到目标的可见编辑入口。放弃完成后，焦点移到原会话的完整输入区域；源草稿终态时移到只读输入或适用的另存入口。操作阶段和按钮禁用原因通过可被辅助技术感知的状态区表达，不能只依赖颜色或短暂消息。

### 键盘与焦点

查看差异及三个版本选择均使用可聚焦的明确控件，推荐选择和风险说明不能仅靠颜色表达。面板打开后，焦点进入面板，Tab 和 Shift+Tab 在面板内移动，背景不能获得焦点；差异内容和展开的技术详情可以通过键盘查看。Enter 只激活当前获得焦点的控件，不因打开面板默认执行另存、丢弃或替换。

Escape 或关闭控件只关闭面板并把焦点送回查看差异入口，持续冲突提示仍然可见；没有发起入口时，焦点回到可用的草稿入口。操作完成并进入新草稿或已保存版本后，焦点转到其可见编辑入口；进入只读计划记录或草稿列表时，焦点转到相应入口。页面以可被辅助技术感知的状态区报告保存、核实和版本变化，不仅依靠瞬时消息传达结果。

## 草稿校验和错误定位

草稿初次打开和普通编辑时不显示校验汇总。用户点击“校验并导出”且当前检查未通过后，在编辑区末尾、导出按钮之前显示中文校验汇总；此后汇总随当前输入更新，全部修正后隐藏。每项说明所属计划或动作以及出错字段，提供可点击的定位入口。原始路径、错误码和原始诊断保留在可展开的技术详情中。字段错误继续通过 `aria-invalid` 标识，控件通过 `aria-describedby` 关联当前错误说明；修正后关联随当前校验结果更新。前端检查未通过时不发出导出请求，后端仍独立校验实际收到的导出输入。

| 校验对象 | 定位结果 |
| --- | --- |
| 表单中有准确对应的公共字段或参数字段 | 展开所属动作及必要的详情，聚焦该字段 |
| 参数或业务策略正在通过 JSON 控件编辑，错误位于其内部路径 | 聚焦负责该对象的 JSON 控件 |
| 参数对象正在通过级联控件编辑，错误可归属到判别字段或当前分支成员 | 展开所属动作并聚焦该模式或成员控件；未选分支的成员不作为当前填写目标，完整组合诊断仍保留 |
| 尚未完成的数值或 JSON 输入 | 聚焦对应的未完成输入原文本，包括根输入；不能以此前的合法值代替 |
| 没有准确控件、动作不是对象、根 JSON 无法解释，或路径有歧义 | 展示并聚焦整份计划 JSON，保留原文和全部编辑资料 |
| 已保存的未完成输入键无法解释为标准路径 | 仍显示原键、原文和错误，定位到该未完成输入控件；应用修正按现有规则报告路径错误 |

定位从当前草稿及稳定动作显示身份计算，兼容现有点号/数组路径和 JSON Pointer。根未完成输入与整份计划 JSON 是两个独立控件。特殊属性名不能无歧义解释时，不把它猜测为另一字段。展开、聚焦或切换 JSON 显示不触发正文修改或保存，也不清除自动预览、暂存参数或未完成输入。Schema 分支及未知关键词使用不臆测具体取值的中文提示，技术详情继续提供完整诊断。

## 拍摄视频大小提示

普通录像和延时摄影动作在拍摄参数编辑区域显示“预计视频大小”，表单模式和参数 JSON 模式共用当前结果。用户修改参数、应用预设、切换设备或类型、重新打开草稿后，页面根据当前参数和实际启用的能力说明重新计算。预览视频和独立照片不计入；其他动作不显示该区域。

有效结果显示约数、预计成片时长和参考码率，并说明实际大小可能随拍摄内容和编码结果变化。大小采用十进制 MB 或 GB，`1 MB = 1,000,000 字节`，`1 GB = 1,000 MB`；参考码率采用 Mbps，即每秒百万比特。显示时才舍入，极小的正估算值以小于某个显示界限表达，不显示为零。

无法估算时，页面区分未提供规则、输入未完成、选择或参数无效、所需值缺失、当前选项没有估算依据及计算无有效结果。必要时显示 Schema 中的字段名称、实际参数路径或既有加载诊断。相关未完成输入立即撤下旧数值；其他动作或无关公共字段的问题不遮蔽当前结果。完整判定顺序与重载恢复条件见[拍摄视频大小估算](../architecture/client-editing.md#拍摄视频大小估算)。

重载进行中和结果尚待核实时，页面显示对应状态并暂停数值。后续合格状态观察成功后，页面按实际启用说明恢复；仍使用此前说明时同时显示该来源提示。查看提示、折叠动作、切换表单与 JSON 或计算结果本身不保存草稿，也不改变自动预览。用户实际编辑参数仍遵守原有保存规则。

## 文件选择及窄屏显示

文件选择使用原生文件输入，键盘焦点由用户可见的外层选择按钮显示。获得焦点或取消文件选择不创建导入批次、不上传文件。实际导入仍遵守[文件导入与结果查看](files-and-status.md)。

窄屏下编辑器标题与工具按钮分行，按钮允许换行，长名称和标识可以在容器内折行。常用辅助文字使用统一的清晰颜色；焦点和错误状态不能仅依靠透明控件自身的轮廓表达。

## 操作反馈

瞬时操作反馈属于发起操作的页面，异步完成时仍归属该页面。每次新反馈从产生时计时 3 秒；同文案的再次反馈重新计时，旧计时不能清除新反馈。离开页面不暂停计时。预设操作反馈同样适用。

| 反馈状态 | 当前页面 | 结果 |
| --- | --- | --- |
| 未满 3 秒且未被替换 | 所属页面 | 显示 |
| 未满 3 秒且未被替换 | 其他页面 | 隐藏，计时继续 |
| 已满 3 秒或已被替换 | 任意页面 | 不再显示原反馈 |

| 信息种类 | 页面范围 | 消失条件 |
| --- | --- | --- |
| 删除、递交标记、预设保存、能力重新加载等操作反馈 | 所属页面 | 产生后 3 秒或被后续反馈替换 |
| 操作错误 | 发起页面 | 下一次操作或问题被处理 |
| 未保存编辑、草稿版本冲突、保存或版本选择结果待核实、异常待决定、独立恢复输入、追加结果待核实 | 计划页 | 按各自规则完成对应处理；关闭差异面板或异常弹窗不解除责任 |
| 后台文件处理错误 | 文件导入页 | 处理状态解除 |
| 服务连接错误、历史覆盖缺口 | 使用这些状态的页面 | 可靠状态恢复 |

## 计划记录折叠

计划详情和每个动作均可独立展开、折叠；计划初次默认展开，动作默认只显示摘要，详见[动作摘要与媒体查看](result-browsing.md)。折叠后仍显示名称及最新状态，详情隐藏。折叠操作不修改请求、报告或执行状态。相同记录的轮询更新和父计划折叠再展开保留动作的折叠状态；切换记录按新记录初始化。控件支持键盘，表达当前展开状态。

## 计划记录分页与定位

计划记录列表保持既有记录顺序，每页最多 10 条，显示总数、当前页与总页数，以及上一页和下一页。首尾按钮禁用。分页只改变列表展示，不改变所选记录或报告状态。

| 情况 | 页面行为 |
| --- | --- |
| 没有记录 | 显示空状态，不显示分页。 |
| 首次查看列表 | 显示第一页。 |
| 翻页或定时刷新 | 保留所选记录；刷新保留当前页码。 |
| 点击当前页的记录 | 更新详情，焦点保留在点击项，不把页面滚动到顶部。 |
| 导出完成或从其他入口进入指定记录 | 显示该记录所在页，程序移动焦点时不触发自动滚动。 |
| 页签切换后返回 | 保留记录列表页码和选择。 |
| 总页数减少、当前页超界 | 显示最后一个有效页。 |

## 文件导入分页

按文件分页，每页最多 10 条，最新导入在前；同一批次可以跨页，每页保留批次标识。分页只影响展示，所有上传、后台处理、报告合并和视频校验仍继续进行。

| 情况 | 页面行为 |
| --- | --- |
| 无导入记录 | 空状态，不显示分页 |
| 首次打开 | 第一页 |
| 翻页 | 显示对应文件及最新处理状态 |
| 定时刷新 | 保留当前页码 |
| 主动选择或拖入新文件 | 回到第一页 |
| 总页数减少，当前页超界 | 显示最后一个有效页 |

显示总文件数、页码、上一页和下一页；首尾按钮禁用。不得通过分页截断实际导入任务。
