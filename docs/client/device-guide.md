# 设备使用说明页

[返回客户端设计](README.md)

本页面向准备拍摄任务的普通使用者，帮助其理解当前设备能做什么、如何选择拍摄任务和参数，以及有哪些使用限制。内容依据后端当前成功启用的能力说明生成，不推测未提供的功能、用途或运行状态。

## 信息布局

1. 顶部介绍使用顺序：了解设备能力，在计划中选择动作类型、目标设备和任务参数并安排执行。说明此页描述可用能力，设备是否在线及执行结果应查看计划记录。
2. 设备按卡片分组，以设备标识为标题，说明支持的任务数量；驱动标识、参数类型标识及原始 Schema 收入默认折叠的技术详情。
3. 每种拍摄任务使用独立卡片：所属拍摄能力、任务名称、完整任务说明、固定设置与可调整内容。能力取自该设备的动作目录，不推断其他设备具有相同能力；通用导语使用拍摄能力和任务设置描述，不预设设备均可录像或调整画质。固定设置直接引用任务说明，不通过文本猜测数值。没有可调整字段时明确标注“固定设置，无需调整参数”。
4. 可调整任务按人类可读字段名展示参数说明。有限组合以紧凑表格展示允许的组合，列名使用字段名称，字符串值不带 JSON 引号。字段是否必填、单位和限制从同源说明中取得。较大的组合目录不铺满页面，提示总量并引导在计划表单中选择。
5. 重新加载及技术诊断放在独立管理区域。加载失败时保留可见错误；存在此前有效说明时，明确指出页面仍展示此前启用的内容。

## 状态与可信范围

| 当前状态 | 页面内容 |
| --- | --- |
| 尚无有效能力说明 | 说明暂不能提供拍摄指南，展示加载诊断与重新加载入口；其他无需相机能力的功能仍可使用 |
| 有效目录为空 | 明确说明尚未配置设备 |
| 设备存在但拍摄能力为空 | 明确说明该设备未提供可用拍摄任务，不解释为离线 |
| 有效任务使用固定设置 | 展示任务说明和固定任务标签 |
| 可枚举任务 | 展示参数说明及实际合法组合；组合为空时明确说明没有满足规则的组合 |
| 有效规则无法可靠枚举 | 展示任务与字段说明，提示复杂参数需在 JSON 编辑中设置；不编造组合表 |

同一规则必须同时驱动编辑页联动和说明页组合展示。技术详情不承担主要说明的职责。页面在窄屏上使用单列卡片，较宽表格在自身区域滚动，不造成整个页面横向溢出。

## 验收

- 演示设备的两种任务可从任务卡片区分；允许组合表仅出现 `4K / 30`、`1080p / 30`、`1080p / 60`，固定任务可直接读到录像时长及画质说明。
- 普通阅读无需展开 Schema；技术详情仍能查看完整原文。
- 空目录、无拍摄能力、说明缺失、重新加载失败保留旧说明分别显示真实状态。
- 桌面和窄屏检查标题层级、任务卡片、表格、管理入口的布局；能力变化后重新计算展示，不保留旧的派生规则。

## 参数类型与预览

设备说明按参数类型展示是否支持预览图片或预览视频。成功重载后，客户端根据[自动预览开关](automatic-previews.md)协调未导出草稿；失败保留已有内容并显示故障。能力支持只表示设备契约，不保证某次拍摄一定产生产物。
