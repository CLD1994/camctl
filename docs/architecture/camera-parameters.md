# 当前相机录像参数

[返回设计总览](README.md) · [阅读路线](reading-guide.md)

本专题定义当前 ADB 相机普通录像的参数组织。录像生命周期见[相机拍摄](camera-recording.md)，框架的参数类型扩展机制见[拍摄能力与参数类型](camera-capabilities.md)，参数规则的导出见[能力说明格式](capabilities.md)。

**阅读提示：** 先了解[拍摄能力、参数类型与预设](camera-capabilities.md#能力参数类型与用户预设)。本页将手动、自动曝光及固定设置分开说明，并区分当前启用的 Action6 普通录像与仍属候选的其他设备组合。

## 适用范围与资料依据

本页记录当前 ADB 相机 `camera_record` 的参数结构；其中 Action6 普通录像是当前启用的生产能力，OSMO 360 II 的定义仍是候选。Action / Action6 与 OSMO 360 / 360 II 的命令和会议记录见[相机控制交接资料整理](../hardware/camera-control-handoff.md)。这些材料用于提取任务意图和候选命令，不能单独证明命令响应或设备能力。

软件集成的设备替身验证与实际设备验收分别记录。ARM 上 Action6 普通录像演示已由用户现场确认一切正常；用户回传还确认客户端生成取回计划并成功独立取回。正式状态报告、媒体和逐项测量未归档，不能据此补写未取得的设备数值或单项证据，具体范围见[现场验收记录](../camctl/verification.md#action6-普通录像演示的现场验收2026-10-11)。Action6 原生延时摄影的设备完成及停止依据尚未核实；OSMO 360 II 仍待完整真机验收，候选能力未启用。Action6 普通录像的现场验收不扩展到这些候选任务，也不把设备替身结果当作真机依据。

本专题定义普通录像的参数组织、曝光分支及下文列出的固定设置。当前驱动和计划实际开放的参数类型由能力说明导出；启用范围及现场验收状态由[相机接入计划](../superpowers/plans/2026-10-10-camctl-real-camera-demo.md#现场验收状态与部署入口)跟踪。交接资料中的 5—20 秒和 8 秒均为参考时长，不据此制定执行计划的时长限制或默认值。

## 普通录像与曝光选择

每个目标驱动在当前普通录像的 `camera_record` 下使用一种参数类型，通过 `params.exposure.mode` 选择曝光方式。手动和自动曝光共享该驱动的普通录像参数类型标识、公共画面参数，以及启动、计时、停止和产物处理流程。

| 字段 | 职责 |
| --- | --- |
| 动作的 `type` | 为 `camera_record`，选择录像动作 |
| `params.type` | 选择目标驱动声明的整套普通录像参数契约；两种曝光方式使用相同标识 |
| `params.duration_s` | 必填数学整数，单位为秒；Action6 与 OSMO 360 II 接受 `1` 至 `9223372036854775`，不设置默认值 |
| `params.exposure` | 必填对象，包含曝光方式及该方式允许的设置 |
| `params.exposure.mode` | 必填字符串；`manual` 表示手动曝光，`auto` 表示自动曝光 |
| `params.exposure` 中的其他字段 | 由所选曝光分支和驱动定义约束 |

`exposure` 属于当前相机的录像参数契约。其他驱动可以按自身任务定义参数结构；框架仍允许一种拍摄能力拥有多种参数类型。客户端预设保存选定设备、参数类型和具体参数值，生成计划时按既有规则展开。

曝光决定画面接收到多少光。快门时间表示每次曝光持续多久，ISO 表示相机的感光增益设置；自动曝光由相机按设备规则调整，曝光补偿 EV 表达在自动结果上希望偏亮或偏暗的程度。白平衡用于处理画面色彩，色温的单位 K 是开尔文。这里先解释这些字段的用途，实际可调范围以已接入驱动为准。

### 普通录像时长

Action6 与 OSMO 360 II 的 `duration_s` 表示主机计时的目标录像秒数。两种曝光方式使用相同的时长规则。整数按 JSON 数值的数学值判断，因此 `1`、`1.0` 和 `1e0` 均表示合法的一秒；字符串不转换为数字。

以下分类以其余录像参数合法为前提。输入必须显式提供时长；Schema 和驱动默认值均不补充该字段。

| 时长输入 | 校验结果 |
| --- | --- |
| 字段缺失 | 参数错误，不补默认值 |
| 为 JSON 数字，数学值为整数，且位于 `1` 至 `9223372036854775` | 校验通过，保留原精确数值 |
| 为 JSON 数字，但数学值不是整数 | 参数错误，不舍入或截断小数秒 |
| 为整数，但小于 `1` 或大于 `9223372036854775` | 参数错误，零不表示无限录像 |
| 为字符串、布尔值、`null`、对象或数组 | 参数错误，不转换类型或推断时长 |

上限由[录像执行定义的目标时长](../camctl/database/execution-definitions.md#录像执行定义的目标时长)的毫秒表示范围确定：最大整数秒为 `9223372036854775807 // 1000`，即 `9223372036854775`。受理后的目标秒数仍精确转换为 `target_duration_ms`，最大合法值对应 `9223372036854775000` 毫秒。该参数范围不承诺设备停止精度；执行、产物完成判定和恢复继续遵守[相机拍摄](camera-recording.md)的规则。

### 曝光分支

| 曝光方式 | 参数组织与执行含义 |
| --- | --- |
| `manual` | 固定曝光设置由动作参数或驱动明确的固定设置确定。开放 ISO 调整时使用 `exposure.iso`；本分支不接受 `exposure.compensation_ev` |
| `auto` | 驱动调用相机的自动曝光功能，曝光补偿使用 `exposure.compensation_ev`。本分支不接受固定 `exposure.iso` 或要求固定快门的输入；相机实际调整的项目与范围由设备契约定义 |

色彩、分辨率、帧率、视角和防抖等设置，按各自字段与设备组合规则定义。选择自动曝光本身不表示这些设置也采用自动控制；白平衡采用下文确定的固定值。

以下 JSON 只展示 `params` 中的 `exposure` 部分，用于说明字段组织，不是可单独提交的完整拍摄参数。示例数值来自交接资料，不定义默认值、完整取值范围或对所有相机的适用性。

手动曝光的结构示例：

```json
{
  "exposure": {
    "mode": "manual",
    "iso": 800
  }
}
```

自动曝光的结构示例：

```json
{
  "exposure": {
    "mode": "auto",
    "compensation_ev": 0
  }
}
```

### MVP 的固定设置

当前普通录像将以下设置作为驱动执行流程的一部分，执行计划不提供相应调整字段：

| 曝光方式 | 快门 | 白平衡色温 |
| --- | --- | --- |
| `manual` | 固定为 `1/60` 秒，由驱动设置 | 固定为 `5200 K`，由驱动设置 |
| `auto` | 按相机的自动曝光规则处理 | 固定为 `5200 K`，由驱动设置 |

驱动在拍摄准备中执行相应设置操作。手动快门的固定值只用于 `manual` 分支，不在进入自动曝光后强制设为 `1/60` 秒。

固定设置属于驱动参数契约，在能力说明的任务说明中展示；客户端不生成调整控件，执行计划不重复填写。参数 Schema 只接受已开放字段，提交额外的快门或白平衡调整字段属于动作自身参数错误，不静默忽略。

后续完整交接确认可调整选项时，可在同一录像参数类型中增加相应字段及约束，并补齐驱动操作映射。沿用既有的驱动定义、同源 JSON Schema 和 `camctl describe` 导出机制，再按部署流程同步客户端；无需为这类字段扩展改变框架的动作接口。已受理动作继续使用首次受理时确定的生效拍摄参数，遵守[参数固化规则](camera-capabilities.md#计划字段与参数校验)。

### Action6 的光圈要求

Action6 普通录像的 `aperture` 是可选字段，适用于 `manual` 和 `auto` 两种曝光方式。省略该字段表示驱动保持相机已有的光圈设置，不发送光圈调整命令；这不表示光圈为某个默认值，也不提供实际光圈的观察。提交 `f2.8` 或 `f4.0` 时，驱动仍按明确要求执行对应设置，设置未确认时不得继续 START。

以下分类以其余录像参数合法为前提。光圈的必填性不影响其他必填字段或曝光分支约束。

| 设备与输入 | 校验及执行结果 |
| --- | --- |
| Action6，未提交 `aperture` | 校验通过；不增加缺省值，不执行光圈调整 |
| Action6，`aperture` 为 `f2.8` 或 `f4.0` | 校验通过；执行该值对应的光圈设置，设置错误或未确认时保留原返回并停止后续准备和 START |
| Action6，`aperture` 为 `null`、其他类型或其他字符串 | 参数错误，不尝试执行 |
| OSMO 360 II，未提交 `aperture` | 按该驱动原有录像参数校验和执行 |
| OSMO 360 II，提交任何 `aperture` 值 | 该驱动没有开放光圈字段，按额外字段判为参数错误 |

首次受理保存的生效参数保留上述区别：省略时仍不含 `aperture`，显式要求时保留原值。执行、恢复和历史报告不得从相机当前状态或演示预设补造缺失的光圈要求，也不得把未调整解释为已核实实际值。

### Action6 的码率要求

Action6 普通录像的 `bitrate` 是可选字段，适用于两种曝光方式。省略时保留设备已有设置，不发送码率调整命令，不生成默认码率或实际码率。明确提交 `standard` 或 `high` 时，驱动执行原值对应的命令；工具的属性匹配、服务连接和注册日志不足以确认设备已经应用该值，因此仅取得这些日志时保留未确认结果，不继续 START。

| 设备与输入 | 校验及执行结果 |
| --- | --- |
| Action6，未提交 `bitrate` | 校验通过，不调整码率；生效参数保持字段省略 |
| Action6，值为 `standard` 或 `high` | 校验通过，执行明确要求；实际设置未确认时停止后续准备和 START |
| Action6，值为 `null`、其他类型或其他字符串 | 参数错误，不尝试执行 |
| OSMO 360 II，提交 `bitrate` | 该驱动没有开放此字段，按额外字段判为参数错误 |

光圈和码率可以各自独立省略。其余必填字段及曝光分支约束不受影响，恢复和报告继续保留省略与显式要求的区别。

### 分支校验

以下规则以设备、动作、参数类型已经匹配到有效定义为前提，按表中顺序判断；每行以此前条件不成立为前提。参数错误沿用[计划字段与参数校验](camera-capabilities.md#计划字段与参数校验)：客户端阻止导出错误计划，camctl 首次受理时仅将对应录像动作登记为 `failed`，保留零次执行尝试，整份拒绝优先级保持既有规则。

| 条件 | 结果 |
| --- | --- |
| `exposure` 缺失、为 `null` 或不是对象 | 参数错误 |
| `mode` 缺失、不是字符串，或值不属于该驱动支持的曝光方式 | 参数错误，不推断曝光方式 |
| `mode` 为 `manual`，但提交了自动曝光补偿字段 | 参数错误，不忽略不适用字段 |
| `mode` 为 `auto`，但提交了固定 ISO 或固定快门设置 | 参数错误，不将固定值解释为自动调整的范围 |
| 曝光方式及前述字段归属合法，但提交了 MVP 未开放的快门或白平衡调整字段 | 参数错误，不覆盖驱动固定设置 |
| 分支选择及字段归属合法，但缺少该驱动要求的字段，或字段值、组合不符合规则 | 参数错误，指出对应字段或组合 |
| 曝光设置及其余拍摄参数均符合有效规则 | 拍摄参数校验通过，继续既有公共字段校验和调度流程 |

条件分支、允许字段及组合约束属于该参数类型的同源 JSON Schema。规则本身无效或无法取得时，遵守既有规则处理失败语义，不判为用户参数错误。

客户端先选择曝光方式，再展示对应成员选项：`manual` 展示 `iso`，`auto` 展示 `compensation_ev`，具体允许值来自当前设备的能力说明。模式切换分别保存并恢复各模式的编辑内容，首次进入时不补子参数；级联编辑与草稿资料的行为遵守[对象参数级联编辑](client-editing.md#对象参数级联编辑)。客户端按相应 Schema 分支校验完整曝光对象，曝光方式或字段改变后按当前完整参数重新校验。其他普通字段的独立选项遵守[参数选项联动](client-editing.md#参数选项联动)，高级编辑与输入保留见[表单与 JSON 共用参数](client-editing.md#表单与-json-共用参数)。切换视图不丢弃字段，也不绕过曝光分支校验；校验不另外维护一套相机字段清单。

## 候选参数与设备验收边界

| 范围 | 当前边界 |
| --- | --- |
| Action6 原生延时摄影 | 软件候选参数不等于设备能力；设备完成、停止及文件完成依据尚未核实，正式能力未启用。按[相机接入计划 T9](../superpowers/plans/2026-10-10-camctl-real-camera-demo.md#t9-设备事实补齐与-arm-linux-完整验收)继续跟踪。 |
| OSMO 360 II | 参数和命令候选尚未构成可执行能力；完整真机响应、文件结果及 ARM 业务链仍待验收，见[相机接入计划 T9](../superpowers/plans/2026-10-10-camctl-real-camera-demo.md#t9-设备事实补齐与-arm-linux-完整验收)。 |
| Action6 可选光圈与码率 | 当前普通录像 Schema 已开放本页定义的可选字段；省略时不执行对应调整。显式要求仍须取得设备设置确认，普通录像演示的现场通过不证明所有可选值已经逐项实测。 |
| 后续参数扩展 | 当前 Schema 未开放的字段不能随计划提交；新增字段须由驱动契约定义、启用并完成相应验证。 |

能力说明仍由驱动定义生成并按[部署交接规则](camera-capabilities.md#部署时向客户端提供说明)同步给客户端。资料中的命令或参考数值不单独构成可用参数定义。
